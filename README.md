# 📚 Library Management ERP System

A dynamic web-based **Library Management ERP System** developed using **PHP, MySQL, HTML, CSS, and JavaScript** to manage books, members, librarians, issue/return transactions, authentication, and library records.

## 📌 Project Overview

This project was developed as part of my **3-month Full Stack Development with PHP internship at Engineers Compass**.

The system is designed to simplify day-to-day library operations through a database-driven web application. It allows library-related information and transactions to be stored, managed, and retrieved dynamically using MySQL.

## ✨ Features

* 📚 Book management
* 👤 Member registration and management
* 👨‍💼 Librarian management
* 🔄 Book issue and return management
* 🔐 User authentication and session management
* 📊 Dashboard with library statistics
* 📝 Library and member records management
* 📈 Transaction and reporting features
* ⚙️ Profile and account management
* 🌐 Dynamic data handling through MySQL database integration

## 🔄 Application Flow

The application follows a database-driven approach:

**User → Web Interface → PHP → MySQL Database → PHP → Web Interface**

Users interact with the web interface, PHP processes the application requests, and MySQL stores and retrieves the required data.
